Ya usas React en tus proyectos, pero probablemente a base de copiar componentes y ajustar. En este curso vamos a construir React desde sus piezas: qué es un componente, cómo fluye la información y cómo se gestiona el estado. Todo con TypeScript y dentro de Astro, que es donde lo usarás.

## Componentes: funciones que devuelven interfaz

Un componente de React es **una función** que devuelve lo que se debe mostrar:

```tsx
export function Saludo() {
  return <h1>Hola, Dani</h1>;
}
```

- El nombre empieza por **mayúscula** (`Saludo`). Así React distingue tus componentes de las etiquetas HTML (`h1`, `div`).
- Se usa como si fuera una etiqueta: `<Saludo />`.
- Un componente puede usar otros componentes: así se construyen interfaces complejas a partir de piezas pequeñas.

## Qué es JSX

Esa sintaxis parecida a HTML dentro de JavaScript se llama **JSX**. No es HTML: el compilador la transforma en llamadas a funciones:

```tsx
<h1 className="titulo">Hola</h1>;
// se convierte en algo como:
jsx("h1", { className: "titulo", children: "Hola" });
```

Por eso JSX tiene reglas propias.

## Diferencias con HTML

| HTML                  | JSX                        | Por qué                                            |
| --------------------- | -------------------------- | -------------------------------------------------- |
| `class="…"`           | `className="…"`            | `class` es palabra reservada en JavaScript         |
| `for="email"`         | `htmlFor="email"`          | `for` también es reservada                         |
| `style="color: red"`  | `style={{ color: "red" }}` | Es un objeto, con propiedades en _camelCase_       |
| `<br>`, `<input>`     | `<br />`, `<input />`      | Toda etiqueta debe cerrarse                        |
| `onclick="…"`         | `onClick={fn}`             | Los eventos van en _camelCase_ y reciben funciones |
| `<!-- comentario -->` | `{/* comentario */}`       | Es JavaScript                                      |

```tsx
export function Campo() {
  return (
    <div style={{ marginTop: 8 }}>
      <label htmlFor="email" className="text-sm">
        Correo
      </label>
      <input id="email" type="email" />
    </div>
  );
}
```

## Expresiones con llaves

Dentro de JSX, las llaves `{}` abren una ventana a JavaScript. Cualquier **expresión** vale:

```tsx
export function Resumen() {
  const nombre = "Dani";
  const leidas = 3;
  const total = 8;

  return (
    <p>
      {nombre}, has leído {leidas} de {total} secciones ({Math.round((leidas / total) * 100)} %).
    </p>
  );
}
```

Solo expresiones: dentro de `{}` no puedes escribir un `if` ni un `for`. Verás cómo resolverlo en la sección B6.4.

## Un solo elemento raíz: fragmentos

Un componente devuelve **un** elemento. Para devolver varios sin añadir un `div` innecesario, usa un **fragmento**:

```tsx
export function Cabecera() {
  return (
    <>
      <h1 className="text-2xl">TypeScript desde cero</h1>
      <p>8 secciones · ~8 h</p>
    </>
  );
}
```

`<>…</>` agrupa sin generar ninguna etiqueta en el HTML final.

## Componer componentes

```tsx
function Titulo() {
  return <h2 className="font-serif text-xl">Contenido del curso</h2>;
}

function Seccion() {
  return <li>Qué es TypeScript y por qué existe</li>;
}

export function Curso() {
  return (
    <section>
      <Titulo />
      <ol>
        <Seccion />
        <Seccion />
      </ol>
    </section>
  );
}
```

Ahora mismo todas las secciones son iguales; en la sección siguiente aprenderás a pasarles datos con **props**.

## React y `.tsx`

Los componentes de React se escriben en archivos `.tsx` (TypeScript + JSX). En un proyecto de Astro, la integración `@astrojs/react` se encarga de compilarlos. Un componente `.tsx` puede importarse y usarse desde una página `.astro`, como verás en la sección B6.7.

<Callout type="note">
  En React 17 y posteriores ya no hace falta `import React from "react"` al principio de cada
  archivo: el compilador lo resuelve solo (`"jsx": "react-jsx"` en el `tsconfig.json`).
</Callout>

## Errores comunes

- **Nombre de componente en minúscula** (`<saludo />`): React lo trata como una etiqueta HTML desconocida.
- **`class` en lugar de `className`**: funciona a medias y TypeScript avisa.
- **Devolver dos elementos sin envolver**: `JSX expressions must have one parent element.`
- **Olvidar cerrar etiquetas** como `<input>` o `<img>`.
- **Poner un `if` dentro de las llaves.** Usa expresiones (ternario, `&&`) o calcula antes del `return`.

  Escribes JSX válido sin errores de sintaxis y entiendes que un componente es una función que
  devuelve interfaz.
</Callout>

## Resumen

- Un componente es una función con nombre en mayúscula que devuelve JSX.
- JSX se compila a llamadas de funciones: no es HTML.
- `className`, `htmlFor`, `style` como objeto y etiquetas siempre cerradas.
- `{}` inserta expresiones de JavaScript.
- Los fragmentos `<>…</>` agrupan sin añadir etiquetas.
