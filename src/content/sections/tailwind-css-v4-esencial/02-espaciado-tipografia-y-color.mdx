El 80 % de una interfaz son espacios, textos y colores. Si dominas sus escalas en Tailwind, tus páginas se verán ordenadas sin esfuerzo. En esta sección aprenderás esas escalas y cómo se combinan para una lectura cómoda, que es el objetivo número uno de esta plataforma.

## La escala de espaciado

Margen (`m`), relleno (`p`), separación (`gap`) y tamaños (`w`, `h`, `size`) usan la **misma escala**: cada paso es `0.25rem` (4 px).

| Clase  | Valor          |
| ------ | -------------- |
| `p-1`  | 0.25rem (4 px) |
| `p-2`  | 0.5rem (8 px)  |
| `p-4`  | 1rem (16 px)   |
| `p-6`  | 1.5rem (24 px) |
| `p-8`  | 2rem (32 px)   |
| `p-12` | 3rem (48 px)   |

Con dirección:

```text
p-4    todo         px-4  izquierda y derecha   pt-4  arriba   pb-4  abajo
m-4    margen       my-4  arriba y abajo        ml-auto  empuja a la derecha
gap-6  separación entre hijos de flex o grid
```

Para separar elementos apilados, `space-y-*` añade margen entre hermanos:

```html
<div class="space-y-2">
  <p>Uno</p>
  <p>Dos</p>
</div>
```

`size-4` fija ancho y alto a la vez (ideal para iconos), y los valores negativos se escriben con guion delante: `-mx-3`.

<Callout type="tip">
  Usar siempre la escala (y no `p-[13px]`) es lo que hace que una interfaz se vea "ordenada". Si
  necesitas un valor fuera de la escala muchas veces, probablemente sea un *token* que falta.
</Callout>

## Tipografía

```html
<h1 class="font-serif text-3xl font-semibold tracking-tight">Arrays, tuplas y objetos</h1>
<p class="mt-4 text-lg leading-relaxed text-slate-700">Casi todos los datos de tus aplicaciones…</p>
```

| Utilidad           | Controla                                               | Ejemplos                               |
| ------------------ | ------------------------------------------------------ | -------------------------------------- |
| `text-*` (tamaño)  | Tamaño de letra (y una altura de línea por defecto)    | `text-sm`, `text-lg`, `text-3xl`       |
| `font-*` (peso)    | Grosor                                                 | `font-medium`, `font-semibold`         |
| `font-*` (familia) | Tipografía                                             | `font-sans`, `font-serif`, `font-mono` |
| `leading-*`        | Altura de línea                                        | `leading-snug`, `leading-relaxed`      |
| `tracking-*`       | Espacio entre letras                                   | `tracking-tight`, `tracking-wider`     |
| `text-balance`     | Reparte el texto de los títulos en líneas equilibradas |                                        |
| `line-clamp-2`     | Corta el texto a 2 líneas con "…"                      |                                        |

### Medida: el ancho de línea

La comodidad de lectura depende sobre todo de la **medida**: entre 60 y 75 caracteres por línea. Más ancho cansa; más estrecho corta el ritmo.

```html
<article class="mx-auto max-w-prose px-4">…</article>
<!-- 65ch -->
<article class="mx-auto max-w-[68ch] px-4">…</article>
<!-- valor arbitrario -->
```

`ch` es el ancho del carácter "0" de la fuente: `68ch` ≈ 68 caracteres. Esta plataforma usa `max-w-[68ch]` en todas las páginas de lectura, con `text-lg` y `leading-relaxed`.

## Color

La paleta por defecto tiene una escala de 50 a 950 por color (`slate-100`, `teal-600`…), y tus _tokens_ de `@theme` se usan igual (`bg-accent`, `text-muted`):

```html
<p class="text-slate-700">Texto</p>
<div class="border border-surface-2 bg-surface">Tarjeta</div>
```

### Opacidad con barra

```html
<div class="bg-accent/10">Fondo tenue del color de acento</div>
<div class="bg-black/50">Velo semitransparente</div>
<p class="text-fg/70">Texto al 70 %</p>
```

`/10` es un 10 % de opacidad **solo en ese color** (el texto de dentro no se ve afectado, a diferencia de `opacity-*`).

<Callout type="warning">
  Cuidado con el contraste al bajar opacidades sobre texto. En esta plataforma, un texto blanco al
  80 % sobre el verde del acento no llegaba al contraste mínimo de accesibilidad (4,13:1 frente a
  4,5:1), y hubo que dejarlo al 100 %.
</Callout>

## Bordes, radios y sombras

```html
<div class="rounded-2xl border border-surface-2 p-6 shadow-sm">…</div>
```

- `border` (1 px), `border-2`, `border-l-4`; color con `border-surface-2`.
- Radios: `rounded-xs`, `rounded-sm`, `rounded-md`, `rounded-lg`, `rounded-xl`, `rounded-2xl`, `rounded-full`.
- Sombras: `shadow-xs`, `shadow-sm`, `shadow-md`… En una interfaz de lectura, úsalas con moderación: un borde suave suele bastar.
- `ring-1` dibuja un contorno que no ocupa espacio (útil en botones y estados de foco).

## Juntándolo todo

```html
<article class="mx-auto max-w-[68ch] px-4 py-12">
  <p class="text-sm text-slate-500">
    <span class="font-semibold text-teal-700">B1.3</span> · Sección 3 de 8 · 60 min
  </p>
  <h1 class="mt-3 font-serif text-4xl font-semibold tracking-tight text-balance">
    Arrays, tuplas y objetos
  </h1>
  <p class="mt-4 font-serif text-lg leading-relaxed text-slate-600">
    Tipar colecciones y objetos, propiedades opcionales y encadenamiento opcional.
  </p>
  <div class="mt-8 rounded-r-xl border-l-4 border-teal-600 bg-slate-100 px-5 py-4">
    <p class="text-xs font-semibold tracking-wider text-slate-500 uppercase">Ejercicio</p>
    <p class="mt-2">Modela con tipos en línea un día de tu app de entrenamiento.</p>
  </div>
</article>
```

## Errores comunes

- **Valores arbitrarios para todo** (`mt-[13px]`): rompen la coherencia de la escala.
- **Texto a lo ancho de la pantalla**: limita la medida con `max-w-prose` o `max-w-[68ch]`.
- **`opacity-*` en un contenedor** cuando solo querías un fondo más claro: usa `bg-color/10`.
- **Bajar contraste por estética** sin comprobarlo.
- **Usar sombras de v3** con los nombres antiguos.

<Callout type="exercise">
  1. Maqueta una página de artículo centrada en la lectura: título, subtítulo, 4 párrafos y un
  cuadro de "Ejercicio", con una medida de unos 65–70 caracteres. 2. Ajusta `leading-*` y `text-*`
  hasta que puedas leer cómodamente varios minutos. 3. Crea tres tarjetas que se diferencien solo
  por un fondo tenue con `bg-color/10` y un borde del mismo color. 4. Comprueba el contraste de tus
  textos con la herramienta de contraste de DevTools (al inspeccionar un texto, en el selector de
  color).
</Callout>

<Callout type="mastery">
  Conoces de memoria la escala de espaciado básica, usas la medida adecuada para la lectura y
  aplicas color con opacidad sin perder contraste.
</Callout>

## Resumen

- Una sola escala de espaciado (pasos de 0.25rem) para `p`, `m`, `gap` y tamaños.
- Tipografía: tamaño, peso, familia, `leading` y `tracking`; `text-balance` para títulos.
- La medida (60–75 caracteres) es la clave de la lectura cómoda.
- `bg-color/10` da opacidad al color sin afectar al contenido.
- Bordes y radios suaves; sombras con moderación.
