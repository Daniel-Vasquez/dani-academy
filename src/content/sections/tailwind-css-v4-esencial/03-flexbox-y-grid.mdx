Casi todo layout es una combinación de dos herramientas: **Flexbox**, para colocar cosas en una fila o una columna, y **Grid**, para colocar cosas en filas **y** columnas a la vez. En esta sección vas a dominar las utilidades de ambos y a construir el layout de una página de curso como la que estás leyendo.

## Flexbox: una dimensión

`flex` convierte un elemento en un contenedor cuyos hijos se colocan en fila (por defecto) o en columna:

```html
<header class="flex items-center justify-between gap-4 px-4">
  <a href="/" class="font-serif text-lg font-semibold">Dani Academy</a>
  <nav class="flex gap-1">…</nav>
</header>
```

| Utilidad                | Controla                     | Valores típicos                                    |
| ----------------------- | ---------------------------- | -------------------------------------------------- |
| `flex-row` / `flex-col` | Dirección                    | fila (por defecto) o columna                       |
| `justify-*`             | Reparto en el eje principal  | `justify-between`, `justify-center`, `justify-end` |
| `items-*`               | Alineación en el eje cruzado | `items-center`, `items-start`, `items-baseline`    |
| `gap-*`                 | Separación entre hijos       | `gap-2`, `gap-6`                                   |
| `flex-wrap`             | Saltar de línea si no caben  |                                                    |

Y en los hijos:

| Utilidad   | Hace                                                                                    |
| ---------- | --------------------------------------------------------------------------------------- |
| `flex-1`   | Ocupa todo el espacio sobrante                                                          |
| `shrink-0` | No se encoge (un icono, una etiqueta)                                                   |
| `ml-auto`  | Se empuja al final                                                                      |
| `min-w-0`  | Permite encogerse por debajo de su contenido (necesario para `truncate` dentro de flex) |

```html
<li class="flex items-start gap-3">
  <span class="flex size-5 shrink-0 items-center justify-center rounded-full border">3</span>
  <span class="min-w-0 flex-1 truncate">Arrays, tuplas y objetos</span>
  <span class="shrink-0 text-xs text-slate-500">60 min</span>
</li>
```

Es la estructura de cada línea del índice de esta plataforma: número fijo, título flexible, duración fija.

### Centrar algo

```html
<div class="flex min-h-dvh items-center justify-center">
  <div class="w-full max-w-sm">Formulario de login</div>
</div>
```

`min-h-dvh` ocupa al menos el alto visible de la pantalla (`dvh` se adapta a las barras de los navegadores móviles).

## Grid: dos dimensiones

`grid` define columnas (y filas), y los hijos se van colocando en ellas:

```html
<ul class="grid grid-cols-3 gap-4">
  <li>B1</li>
  <li>B2</li>
  <li>B3</li>
  <li>B4</li>
  <li>B5</li>
  <li>B6</li>
</ul>
```

| Utilidad        | Hace                                       |
| --------------- | ------------------------------------------ |
| `grid-cols-3`   | 3 columnas iguales                         |
| `col-span-2`    | El hijo ocupa 2 columnas                   |
| `col-start-2`   | Empieza en la columna 2                    |
| `grid-rows-7`   | 7 filas                                    |
| `grid-flow-col` | Rellena por columnas en lugar de por filas |

### Valores arbitrarios para rejillas a medida

Entre corchetes puedes escribir cualquier valor de CSS (los espacios se escriben con `_`):

```html
<!-- Barra lateral de 18rem y contenido que ocupa el resto -->
<div class="grid grid-cols-[18rem_minmax(0,1fr)] gap-12">
  <aside>Índice</aside>
  <main>Contenido</main>
</div>

<!-- Tantas columnas de al menos 16rem como quepan -->
<ul class="grid grid-cols-[repeat(auto-fill,minmax(16rem,1fr))] gap-4">
  …
</ul>
```

`minmax(0,1fr)` en lugar de `1fr` evita que un contenido muy ancho (un bloque de código) estire la columna.

## ¿Flex o Grid?

- **Flex**: elementos en **una línea** cuyo tamaño depende de su contenido. Cabeceras, botones con icono, una fila de etiquetas, el contenido de una tarjeta.
- **Grid**: una **estructura** en filas y columnas donde el layout manda sobre el contenido. Rejillas de tarjetas, layouts de página, el mapa de actividad de la página de progreso (7 filas, 12 columnas).

Se combinan sin problema: un grid de tarjetas donde cada tarjeta usa flex por dentro.

## El layout de una página de curso

```html
<div class="min-h-dvh">
  <header class="sticky top-0 z-30 flex h-14 items-center border-b px-6">…</header>

  <div class="mx-auto max-w-7xl lg:grid lg:grid-cols-[18rem_minmax(0,1fr)] lg:gap-12 lg:px-6">
    <aside class="hidden lg:block">
      <div class="sticky top-14 max-h-[calc(100dvh-3.5rem)] overflow-y-auto py-8">Índice</div>
    </aside>
    <main class="min-w-0 px-4 py-10">
      <article class="mx-auto max-w-[68ch]">…</article>
    </main>
  </div>
</div>
```

- `sticky top-0` fija la cabecera al hacer scroll; `sticky top-14` fija el índice justo debajo.
- `max-h-[calc(100dvh-3.5rem)] overflow-y-auto` hace que el índice tenga su propio scroll si es muy largo.
- El prefijo `lg:` activa el grid solo en pantallas grandes (sección B7.4).

## Errores comunes

- **Olvidar `min-w-0`** en un hijo flexible con texto largo: desborda en lugar de cortarse.
- **`1fr` en columnas con código o tablas**: usa `minmax(0,1fr)`.
- **Márgenes en lugar de `gap`** para separar hijos.
- **Grid para una simple fila de botones**, o flex con cálculos de ancho para una rejilla.
- **Espacios dentro de los corchetes**: `grid-cols-[18rem 1fr]` no funciona; usa `_`.

## Resumen

- Flex coloca en una dimensión: `justify-*`, `items-*`, `gap`, `flex-1`, `shrink-0`.
- Grid coloca en dos: `grid-cols-*`, `col-span-*`, `grid-rows-*`.
- Valores arbitrarios entre corchetes, con `_` en lugar de espacios.
- `min-w-0` y `minmax(0,1fr)` evitan desbordamientos.
- `sticky` y `max-h` con `overflow-y-auto` construyen cabeceras e índices fijos.
